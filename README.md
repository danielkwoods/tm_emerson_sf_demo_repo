# Telco Customer 360 Dashboard

A comprehensive Streamlit dashboard for telco sales teams to analyze customer data and make informed decisions.

## Features

### 🏠 Customer Overview
- Individual customer profiles with key metrics
- Service plan details and usage summaries
- Recent interaction history
- Usage trends and billing history

### 📱 Service Usage Analytics
- Detailed usage pattern analysis
- Usage distribution by plan type and customer tier
- Overage analysis and trends
- Top usage customers identification

### 💰 Revenue & Billing Analysis
- Comprehensive revenue breakdown
- Payment status analysis
- Revenue trends over time
- Customer tier revenue analysis
- Overage revenue insights

### 🛤️ Customer Journey & Interactions
- Customer interaction tracking
- Satisfaction analysis
- Journey stage mapping
- Agent performance metrics
- Interaction trends over time

### ⚠️ Churn Risk & Retention Insights
- Advanced churn risk scoring
- High-risk customer identification
- Retention strategy recommendations
- Risk analysis by customer segments
- Action items for retention campaigns

## Installation

1. Clone or download this repository
2. Install required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```

2. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:8501`)

3. Use the sidebar navigation to explore different sections of the dashboard

## Data

The application generates realistic telco customer data including:
- Customer demographics and profiles
- Service plans and pricing
- Usage patterns (data, voice, text)
- Billing and payment information
- Customer interactions and satisfaction scores
- Churn risk assessments

## Features

- **Interactive Filters**: Filter data by customer tier, plan type, and time period
- **Real-time Metrics**: Key performance indicators and KPIs
- **Visual Analytics**: Charts, graphs, and trend analysis
- **Customer Segmentation**: Analysis by customer tiers and segments
- **Risk Assessment**: Churn prediction and retention insights
- **Actionable Insights**: Recommendations for sales and retention teams

## Technical Details

- Built with Streamlit for the web interface
- Uses Plotly for interactive visualizations
- Pandas for data manipulation
- NumPy for numerical computations
- Modular page structure for easy maintenance

## Customization

The dashboard can be easily customized by:
- Modifying the data generator in `data_generator.py`
- Adding new pages in the `pages/` directory
- Updating the styling in the main `app.py` file
- Adding new metrics and visualizations

## Support

For questions or issues, please refer to the Streamlit documentation or create an issue in the repository.
